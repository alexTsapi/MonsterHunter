# Monster Hunter – Κυνήγι Τεράτων

Παιχνίδι για τάμπλετ, από ιδέα ενός 6χρονου κυνηγού τεράτων.

- 5 κόσμοι: Πόλη, Δάσος, Παραλία, Χιόνια, Στοιχειωμένο, και στο τέλος κάθε κόσμου ένας αρχηγός
- Σκυλάκι-βοηθός που γαβγίζει όταν βρει κρυμμένο τέρας
- Άλμπουμ με 8 τέρατα και 5 αρχηγούς
- Δώρα: καρδιά, ασπίδα, παπούτσια ταχύτητας, μαγνήτης κυπέλλων
- 5 όπλα: παίρνεις ένα καινούργιο κάθε φορά που νικάς αρχηγό
- Αποθηκεύει μόνο του

## Πώς βγαίνει το APK

Κάθε φορά που αλλάζει κάτι στο repository, το GitHub φτιάχνει μόνο του νέο APK (καρτέλα **Actions**).
Την πρώτη φορά θέλει 30–40 λεπτά. Τις επόμενες είναι πιο γρήγορο.

Όταν τελειώσει, το APK βρίσκεται στα **Releases** (δεξιά στη σελίδα του repository).

## Εγκατάσταση στο τάμπλετ

1. Στο τάμπλετ άνοιξε τη σελίδα του repository → **Releases** → το πιο πρόσφατο.
2. Πάτα το αρχείο `monsterhunter-...-debug.apk` για να κατέβει.
3. Άνοιξέ το. Αν το Android ρωτήσει, επίτρεψε την «Εγκατάσταση από άγνωστες πηγές» για τον browser.
4. Πάτα **Εγκατάσταση**.

## Παιχνίδι στο PC

```
pip install pygame
python main.py
```
